# 트러블슈팅 — 첫 외부 접속 실패

| 단계 | 실제 확인 |
|---|---|
| 증상 | EC2 실행 직후 외부 `curl http://54.180.255.77/health`가 종료 코드 7로 연결 실패 |
| 가설 | 부팅 직후 Nginx 설치·시작이 아직 끝나지 않았을 수 있음 |
| 검증 | 라우트 `0.0.0.0/0 → IGW`는 `active`, SG 80은 전체 공개, SSH 22는 개인 IP로 제한된 것을 확인 |
| 조치 | 7초 후 같은 URL 재요청; 이후 SSH에서 Nginx `active`, 내부 `/`·`/health` 200 확인 |
| 결과 | 외부 `/health`가 **200 OK**, 본문 `OK`를 반환하고 브라우저에서 페이지 표시 |
| 재발 방지 | 인스턴스 실행 직후 곧바로 외부 요청을 판정하지 않고, 서버 상태와 `localhost` 응답을 먼저 확인 |

원인을 로그로 확정하지는 못했으며, 부팅 중 서비스 준비 지연이라는 가설이 후속 응답으로 뒷받침됐다.
