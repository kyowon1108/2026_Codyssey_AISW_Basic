# B4-1 리눅스 서버 운영과 관제 자동화

## 수행 내용

Ubuntu 22.04 환경에서 SSH·방화벽·역할별 권한과 애플리케이션 실행 환경을 구성함.
관제 스크립트와 cron으로 주기 수집과 로그 용량 관리를 자동화함.

## 실습 설정

| 항목 | 적용값 |
|---|---|
| 환경 | Ubuntu 22.04.5 LTS, ARM64 Docker 컨테이너임 |
| SSH | 20022번을 사용하고 root 원격 접속을 차단함 |
| 방화벽 | 20022·15034번만 허용함 |
| 권한 | 계정 3개·그룹 2개와 ACL로 공유·보안 영역을 구분함 |
| 관제 | 매분 실행하며 로그 10MB·최대 10개를 유지함 |

## 검증 결과

일반 계정 SSH 성공과 root·22번 접속 거부, 계정별 접근 테스트 7종을 확인함.
앱 준비 상태, 관제 예외·임계값 경고, cron 로그 누적을 확인하고 [수행내역서](docs/수행내역서.md)에 원본 증거를 연결함.

## 발견한 문제

좀비·무관한 프로세스를 앱으로 판단한 오탐과 종료 후 자식 프로세스 잔존을 수정함.
cron의 PATH와 방화벽 조회 권한 문제를 해결함.

## 수행 범위

필수 관제와 용량 기반 로그 관리를 구현함.
선택 과제인 통계 리포트와 시간 기반 로그 보존은 미수행임.
