
================================================================
[설정] 적용된 SSH 설정
================================================================

$ sshd -T | grep -iE '^(port|permitrootlogin|passwordauthentication) '
port 20022
permitrootlogin no
passwordauthentication yes
(exit code: 0)

================================================================
[검증 1] 변경된 포트(20022)로 일반 계정 로그인
================================================================

$ sshpass -p 'Codyssey!2026' ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o ConnectTimeout=5 -o LogLevel=ERROR -p 20022 agent-admin@127.0.0.1 'echo 로그인 성공: $(whoami)@$(hostname); id'
로그인 성공: agent-admin@agent-lab
uid=1000(agent-admin) gid=1002(agent-admin) groups=1002(agent-admin),1000(agent-common),1001(agent-core)
(exit code: 0)

================================================================
[검증 2] 기존 포트(22)로는 접속되지 않음
================================================================

$ sshpass -p 'Codyssey!2026' ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o ConnectTimeout=5 -o LogLevel=ERROR -p 22 agent-admin@127.0.0.1 'whoami'
ssh: connect to host 127.0.0.1 port 22: Connection refused
(exit code: 255)

================================================================
[검증 3] Root 원격 로그인 차단
================================================================
  -> 비밀번호가 틀려서 거부되는 것이 아님을 보이기 위해 root 비밀번호를 임시로 설정한다

$ echo 'root:Codyssey!2026' | chpasswd && echo 'root 비밀번호 임시 설정 완료'
root 비밀번호 임시 설정 완료
(exit code: 0)
  -> 올바른 비밀번호를 주더라도 PermitRootLogin no 때문에 거부되어야 한다

$ sshpass -p 'Codyssey!2026' ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o ConnectTimeout=5 -o LogLevel=ERROR -p 20022 root@127.0.0.1 'whoami'
Permission denied, please try again.
(exit code: 5)
  -> 검증 후 root 계정을 다시 잠근다

$ passwd -l root >/dev/null && passwd -S root
root L 08/22/2026 0 99999 7 -1
(exit code: 0)
