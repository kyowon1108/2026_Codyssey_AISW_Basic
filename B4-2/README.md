# B4-2 시스템 장애 분석

## 수행 내용

제공 ARM64 바이너리를 일반 사용자로 실행해 OOM·CPU·Deadlock의 환경변수 변경 전후를 비교함.
바이너리 분석 없이 실행 로그와 OS 관제 수치를 근거로 이슈 리포트 3건을 작성함.

## 실험 환경

| 항목 | 적용값 |
|---|---|
| 환경 | Ubuntu 22.04, ARM64 Docker 컨테이너임 |
| 자원 제한 | 컨테이너 768MB·1CPU임 |
| 관찰 시간 | 최종 비교 실험은 케이스당 60초임 |
| 네트워크 | 컨테이너 내부 15034번을 사용하며 호스트 포트는 공개하지 않음 |

## OOM 비교

메모리 한도를 50MB에서 100MB로 변경하자 생존 시간이 6초에서 12초로 증가함.
두 실행에서 MemoryGuard 종료를 확인하고 [OOM 리포트](docs/issues/01-oom.md)에 기록함.

## CPU 비교

설정을 100%에서 10%로 변경하자 Watchdog의 31초 종료와 60초 관찰 생존의 차이를 확인함.
변경 전 CPU 구간 관제 최대값은 5.04%로 실제 CPU 과점유·응답 지연은 입증하지 못했으며 [CPU 리포트](docs/issues/02-cpu.md)에 한계를 기록함.

## Deadlock 비교

멀티스레드 활성 상태에서 PID 유지·수치 정체·순환 대기 로그를 관측함.
비활성 상태에서는 작업 완료를 확인하고 [Deadlock 리포트](docs/issues/03-deadlock.md)에 비교함.
