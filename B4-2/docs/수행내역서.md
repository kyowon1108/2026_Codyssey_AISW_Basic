## 증거와 한계

[스크린샷 4장](evidence/20261004T054929Z-1413/screenshots/)은 Docker 원본 출력을 읽기 전용 브라우저 화면에 표시해 캡처한 것임. Terminal 화면이나 실시간 Docker Desktop 화면으로 표기하지 않으며, [원본 로그](evidence/20261004T054929Z-1413/)·HTML 발췌 화면·실행 당시 스크립트도 보관함.

앱 내부 CPU 부하는 50.86%였지만 구간 OS 관제 최대값은 5.04%임. top 첫 샘플의 26.7%도 임계치 초과 증거로 볼 수 없어 실제 CPU 과점유·응답 지연은 미확인임. 설정 변경 후 생존은 60초 관찰 범위의 결과이며 메모리 증가까지 해결한 것은 아님.

관찰 종료는 `result.txt`의 `experiment_timeout`과 `harness.log`로 구분하고 정리 전에 관제를 중단함. 이전 2026-10-02 탐색·오류 로그는 보존하며, 제출 기준은 위 2026-10-04 실행임. 선택 스케줄링 추론과 별도 GitHub Issue 게시는 미수행임.
