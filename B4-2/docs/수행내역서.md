# B4-2 수행내역서

2026-10-02 제공 ARM64 바이너리를 Ubuntu 22.04 컨테이너에서 일반 사용자로 실행했다. 바이너리 디컴파일 없이 환경변수·출력·OS 관제를 비교했다.

| 요구사항 | 수행 결과 | 검토 자료 |
|---|---|---|
| 실행 준비 | 계정·환경변수·키·권한·15034 바인딩, 6개 부트 검사 통과 | 각 실험 config.txt / application.log |
| OOM 2회 비교 | 50→100MB, 생존 6→12초, MemoryGuard/SIGKILL | [OOM 이슈](issues/01-oom.md) |
| CPU 2회 비교 | 100→10%, Watchdog 37초 종료→45초 관찰 생존 | [CPU 이슈](issues/02-cpu.md) |
| Deadlock 2회 비교 | true→false, 순환 대기→작업 완료 | [Deadlock 이슈](issues/03-deadlock.md) |
| 원본 증거 | 관제 CSV·앱 로그·ps·스레드 top·cgroup·종료 결과 | [최종 비교 실험](evidence/20261002T054757Z-69135/) |

**CPU 증거 한계:** 앱 내부 부하는 52.70%까지 증가했지만 OS 측정 최대 CPU는 5.88%였다. Watchdog 종료는 입증했으며, 실제 CPU 과점유·응답 지연은 입증하지 못했다. 이 항목을 완전 충족으로 표시하지 않는다.

## 검증과 제출

재현은 [README](../README.md)를 따른다. 최종 비교 실험은 케이스당 45초로 제한했다. 자동 검증은 Linux에서 `bash scripts/verify.sh 20261002T054757Z-69135`로 실행하며 [검증 원본](evidence/preflight/verification.txt)에 결과를 저장한다. [ShellCheck](evidence/preflight/shellcheck.txt), [이미지 빌드](evidence/preflight/docker-build.log), [관제 단독 확인](evidence/monitor-smoke/)도 별도 보관한다.

앞선 `20261002T054348Z-63341`은 `/tmp` 실행 권한 문제로 부트 실패한 기록이다. `20261002T054411Z-63962`, `20261002T054517Z-65731`은 설정 탐색 중 중단한 실행이며 제출 비교에서 제외했다. 최종 비교의 6건 완료 뒤 실행 중 스크립트 수정으로 runner에 구문 오류가 남았으나, 저장 증거의 독립 검증은 통과했다. 정리 이후 샘플은 분석에서 제외하며, 수정한 종료 처리는 [3초 재실행](evidence/20261002T055246Z-75243/runner.log)으로 정상 완료를 확인했다.
